Nodo

Un nodo es cada uno de los elementos que componen un documento HTML o XML. El DOM (Document Object Model) representa la estructura del documento como un árbol de nodos, donde cada nodo puede ser un elemento, un atributo, un texto, etc.

Tipos de nodos

  • Nodo de documento: Representa el documento completo.
  • Nodo de elemento: Representa un elemento HTML o XML (por ejemplo, <div>, <p>, <a>).
  • Nodo de texto: Contiene el texto dentro de un elemento o atributo.
  • Nodo de atributo: Representa un atributo de un elemento (por ejemplo, id, class).
  • Nodo de comentario: Representa un comentario en el código HTML o XML.

Manipulación del DOM con JavaScript

JavaScript proporciona varias formas de acceder y manipular los nodos del DOM. Algunas de las funciones más comunes incluyen:

  • document.getElementById(): Selecciona un elemento por su ID.
  • document.getElementsByTagName(): Selecciona elementos por su etiqueta.
  • document.getElementsByClassName(): Selecciona elementos por su clase.
  • document.querySelector(): Devuelve el primer elemento que coincida con el grupo especificado de selectores
  • document.querySelectorAll(): Devuelve todos los elemento que coincidan con el grupo especificado de selectores
  • element.innerHTML: Permite cambiar el contenido HTML de un elemento.
  • element.style: Permite cambiar los estilos CSS de un elemento.
  • element.appendChild(): Añade un nuevo nodo hijo a un elemento.
  • element.removeChild(): Elimina un nodo hijo de un elemento.
